TalkTag script–picture audit

6 November 2026 · English, Korean and Japanese · Source and asset review; no website changes or audio generation.

Coverage

375 catalog cards: 302 Sound Check, 60 Boot Camp and 13 Readable. Actual rendered image files were visually inspected in contact sheets and compared with lesson expressions, scene descriptions and available authoring/release records. 369 cards resolve to 197 distinct local pictures. Six English Readable records contain no configured artwork.

357 cards have no obvious scene contradiction in this source review; 10 English GLR 011 cards need more precise artwork; two Korean C2 Boot Camp cards warrant emotional-detail refinement. Six English Readable cards need an explicit decision about whether to add artwork. A shared image is acceptable for split parts or versions of the same story; reuse alone is not a failure.

Evidence and limits

Inventory: current production public/catalog-metadata.js; same-day private Sound Check inventory; original A1 008–010 pilot scripts; approved English GLR 012 canonical scripts; Boot Camp authoring modules and published bootcamp-artwork.js; Korean Readable release SQL. Private lesson text remains outside the public deployment.

This is not a complete authenticated live-player audit. The 60 Boot Camp and 13 Readable records were reviewed from local authoring/release sources. Boot Camp artwork resolver entries exist, but this session did not independently export all current Supabase payloads or prove each protected player's binding. Six English Readable records have no artwork mapping in the inspected source; absence is not classified as a broken live image. Do not report 100% live verification from this report.

Main findings

English GLR 011: the shared station illustration visibly contains signs 3 and 4, while A1 asks for platform 2. Other levels use materially different station problems. Create one scene per level, retaining shared artwork only between split parts of that level. This is one specific number conflict plus wider scene-specificity concerns, not ten proven unrelated pictures.

Korean Boot Camp C2 002: both Vocal and Story use the same café comic. Setting, blue bag and initial uncertainty fit, but the large cheerful ending underplays the tense and ambiguous exchange. Adjust expressions and emphasis.

English GLR 012: six distinct level scenes are now present; the previous all-level cup-image problem is corrected in current public metadata. The protected player prioritizes that metadata, while old stored payload artwork should be reconciled to avoid future regression.

Acceptable reuse: Korean/Japanese GLR 001 share closely parallel situations; Korean Readable A0–C2 follow one bus-delay story; Boot Camp level variants generally preserve their family situation. These were not marked wrong merely because artwork is shared.
