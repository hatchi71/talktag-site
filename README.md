# TalkTag interactive concept

Open `index.html` in a modern browser. No install or server is required. The layout is designed around a mobile-first vertical flow: a persistent top identity bar and a five-item bottom navigation. Wider screens expand this into the canvas workspace.

The primary sidebar navigation is intentionally limited to:

- HOME
- MySpace
- Talk
- Tag
- Snowballing Studio

Snowballing Studio currently contains two paths: **Listen & Repeat** and **Reads**.

The original TalkTag logo and supplied supporting assets are retained alongside the new single-page prototype.
