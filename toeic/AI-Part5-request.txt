TOEIC Listening & Reading Part 5 형식에 맞는 실전 연습 문제를 정확히 30문항(101~130) 생성하세요. 다른 파트 문제는 포함하지 마세요.

이 작업의 핵심 목표는 단순히 30개의 새로운 문장을 만드는 것이 아니라, 학습자가 가능한 한 서로 다른 30개의 판단 경험을 하도록 만드는 것입니다.

같은 단어를 쓰지 않았더라도 동일한 문법 단서, 동일한 연어 구조, 동일한 문장 골격, 동일한 해결 알고리즘을 요구한다면 구조적으로 중복된 문제로 간주하세요.

1. FIXED OUTPUT MANIFEST

101, 102, 103, ... , 129, 130

추가 문제, 보너스 문제, 수정본, 대체 문제를 배열 뒤에 덧붙이지 마세요.

문항을 수정해야 할 경우 해당 번호의 기존 문항을 교체하세요.

130번 객체가 마지막 객체이며, 그 직후 JSON 배열을 닫으세요.

2. INTERNAL GENERATION BLUEPRINT
────────────────────────────────

문제를 쓰기 전에 아래 30개 Generation Slot을 내부적으로 각각 정확히 한 번씩 배정하세요.

이 설계표는 출력하지 마세요.

문항 번호와 Slot의 배치는 매번 섞어서 사용하세요.

[Grammar & Structure — 정확히 14문항]

G01. 명사 자리와 품사
- 관사/소유격/형용사 + 명사
- 명사형과 형용사·동사형 구별

G02. 형용사와 부사
- 동사 수식
- 형용사 수식
- be동사 뒤 보어
- 명사 앞 형용사

G03. 진짜 주어와 수일치
- 전치사구, 관계절, 분사구 등 수식어를 제거한 뒤 주어 판단

G04. 수량·부분 표현과 수일치
- a number of / the number of
- one of / each of / several of / all of 등

G05. 시제와 상
- since / for / over the past
- before / by the time / recently 등
- 시간 관계를 함께 판단

G06. 능동태·수동태·타동성
- 행위자와 대상의 관계
- 목적어 존재 여부

G07. 명사를 수식하는 분사
- N + -ing
- N + p.p.
- 명사와 분사의 의미상 능동·수동 관계를 판단
- “자동사는 무조건 -ing” 같은 과도한 규칙은 사용하지 말 것

G08. 동명사와 to부정사
- consider/avoid + -ing
- plan/decide/agree + to V 등

G09. 목적어 + 목적격 보어
- make/find/keep/consider + O + adj/p.p.
- allow/encourage/expect + O + to V 등

G10. 수동태 + to부정사
- be required/expected/allowed/encouraged + to V

G11. 전치사와 접속사
- despite / although
- because of / because
- during / while 등
- 뒤에 명사구가 오는지 절이 오는지 판단

G12. 관계사·대명사
- who / whom / whose / which / that
- those / themselves 등
- 절 안에서 실제로 비어 있는 성분을 판단

G13. 수량·비교 구조
- many/much, few/little
- fewer/less
- another/other
- 비교급 강조 표현 등

G14. Advanced Rotation
다음 중 하나만 선택:
- 주장·요구·제안 + that + 동사원형
- whether + to V
- 축약 부사절
- 상관접속사·평행구조
- It + be + adj + to V
- 조건문
- 자연스러운 경우에 한한 도치

G14는 희귀하거나 인위적인 문장을 만들기 위한 슬롯이 아닙니다.
실제 업무 영어에서 자연스러운 구조만 사용하세요.

[Lexical, Collocation & Context — 정확히 16문항]

L01. 사무·행정 동사
L02. 인사·채용·교육
L03. 구매·조달
L04. 배송·물류
L05. 제조·품질관리
L06. 금융·회계·청구
L07. 일정·회의·행사
L08. 출장·여행·숙박
L09. 고객서비스·소매
L10. 시설관리·IT 운영
L11. 형용사 의미 선택
L12. 부사 의미 선택
L13. 명사 의미 선택
L14. 동사/형용사 + 전치사 연어
L15. 복합명사
L16. 업무용 고정 표현·구
예: in advance, in effect, on behalf of, be subject to, carry out 등

Lexical 문제는 단순한 단어 뜻 암기보다 문맥과 자연스러운 연어를 함께 판단하도록 만드세요.

────────────────────────────────
3. STRUCTURAL FINGERPRINT
────────────────────────────────

각 문항을 내부적으로 다음 요소로 분석하세요.

[Generation Slot]
+ [실제 측정 포인트]
+ [문장 골격]
+ [오답 설계 방식]
+ [업무 상황]
+ [핵심 정답어 또는 연어]

이를 Structural Fingerprint라고 합니다.

다음은 같은 세트 안에서 금지합니다.

- 같은 정답 단어의 반복
- 같은 핵심 연어의 반복
- 단어만 바꾸고 동일한 문법 판단을 다시 요구하는 문제
- 같은 문장 골격과 같은 해결 단서를 동시에 사용하는 문제
- 회사명·인물명·사건만 바꾼 사실상 동일한 문제
- 같은 상황의 반복적 변형

예를 들어
“comply ------- regulations”와
“adhere ------- procedures”가 모두 단순히 동사 뒤 전치사 하나만 기억하면 풀리는 구조라면 가까운 Structural Fingerprint로 판단하세요.

가능하면 서로 떨어뜨리거나 다른 판단 요소를 추가하세요.

────────────────────────────────
4. CROSS-SET ROTATION
────────────────────────────────

이 대화나 입력 문맥에 이전 Part 5 세트가 존재한다면 자동으로 최근 생성 이력으로 사용하세요.

최근 세트와 비교하여 가능한 한 다음을 피하세요.

- 최근 2개 세트에서 정답으로 사용한 동일 lemma
- 최근 3개 세트에서 사용한 동일 핵심 collocation
- 최근 2개 세트에서 사용한 거의 동일한 Structural Fingerprint
- 반복되는 대표 상황과 문장 skeleton
- 특정 AI 선호 표현의 과잉 반복

특히 available, eligible, confirm, submit, promptly, comply, require, provide 같은 편리한 단어에 습관적으로 의존하지 마세요.

이 단어들을 금지하는 것은 아닙니다.
최근 사용 빈도를 고려하여 회전시키세요.

이전 세트가 제공되지 않았다면 이 규칙을 추측해서 적용하지 말고 현재 세트 내부의 다양성만 관리하세요.

정확성과 자연스러움이 항상 회전 규칙보다 우선합니다.

문법 항목이 달라도 모든 문제가

F02. 전치사구·시간구 등을 문두에 둔 문장

F04. To V 목적 표현으로 시작하는 문장

F08. It/There 등 특수 주어 구조
F09. 분사·축약절로 시작하는 문장
F10. 비교·조건·기타 자연스러운 변형 구조

6. DIFFICULTY DESIGN
────────────────────────────────

정확히 다음 정도의 체감 난이도로 설계하세요.

- 중: 약 6문항
- 중상: 약 18문항
- 상: 약 6문항

난이도를 희귀 단어, 전문지식, 지나치게 긴 문장으로 올리지 마세요.

난이도는 판단 단계의 수로 조절하세요.

중:
한 가지 분명한 단서로 해결 가능

중상:
두 가지 정도의 단서를 함께 판단
예:
- 주어 파악 + 수일치
- 시간 표현 + 시제
- 품사 + 문맥
- 의미 + 연어

상:
두세 단계의 판단이 필요
예:
- 긴 주어 파악 + 태 + 시제
- 절 구조 + 접속 관계 + 의미
- 네 선택지가 모두 문법적으로 가능하지만 문맥·연어로 하나를 선택

어려운 문제라도 정상적인 현대 업무 영어여야 합니다.

9. DISTRACTOR ENGINEERING
────────────────────────────────

먼저 문장과 실제 정답을 결정하세요.
그 후 오답 세 개를 만드세요.

어휘·연어 문제:
- 가능한 한 네 선택지를 같은 품사로 맞추세요.
- 비슷한 의미 범주 또는 업무 문맥에서 실제로 쓰이는 단어를 사용하세요.
- 오답도 문법적으로 들어갈 수 있지만 의미·연어·상황 때문에 탈락하도록 만드는 것을 우선하세요.

문법 문제:
- 실제 학습자가 혼동할 수 있는 형태를 사용하세요.
- 철자가 비슷하다는 이유만으로 오답을 만들지 마세요.

모든 오답은 실제로 빈칸에 대입하여 검사하세요.

오답은 다음 중 적어도 하나의 명확한 이유로 탈락해야 합니다.

- 품사
- 수일치
- 시제
- 태
- 문장 구조
- 목적어 유무
- 전치사 결합
- 가산성·수량
- 시간 관계
- 의미
- 연어
- 지시 관계

두 개 이상의 선택지가 자연스럽게 성립한다면 해당 문제를 폐기하지 말고 같은 번호에서 수정 후 다시 검수하세요.

정답만 유난히 길거나 구체적이지 않게 하세요.

────────────────────────────────
10. ANSWER POSITION CONTROL
────────────────────────────────

최종 정답 분포:

A = 정확히 8
B = 정확히 8
C = 정확히 7
D = 정확히 7

같은 정답 문자가 3문항 이상 연속되면 안 됩니다.

ABCD ABCD처럼 눈에 띄는 기계적 반복 패턴도 피하세요.

중요:
정답 위치를 먼저 정하고 문제를 억지로 맞추지 마세요.

순서:
1. 문장을 만든다.
2. 실제 정답을 결정한다.
3. 오답을 만든다.
4. 문제를 다시 푼다.
5. 그 후 choices 순서를 재배열해 전체 정답 위치 분포를 맞춘다.
6. answer, vocab, explanation을 최종 선택지 순서에 맞게 모두 업데이트한다.

────────────────────────────────
11. JSON SCHEMA
────────────────────────────────

각 객체는 정확히 다음 필드만 사용하세요.

{
  "part": 5,
  "question": "빈칸 ------- 이 하나 포함된 영어 문장",
  "choices": ["A 보기", "B 보기", "C 보기", "D 보기"],
  "answer": 0,
  "translation": "정답을 넣어 완성한 전체 문장의 자연스러운 한국어 해석",
  "vocab": "A~D 네 보기의 뜻과 각각의 짧은 영어 예문",
  "explanation": "지정된 네 섹션으로 구성된 한국어 설명"
}

answer:
A = 0
B = 1
C = 2
D = 3

choices의 문자열 안에는 (A), (B), (C), (D)를 붙이지 마세요.

12. VOCAB FIELD
────────────────────────────────

각 선택지에:

정답뿐 아니라 오답도 모두 설명하세요.

────────────────────────────────
13. EXPLANATION — MANDATORY FORMAT
────────────────────────────────

모든 explanation은 정확히 다음 네 섹션을 이 순서로 포함하세요.

{문항번호}. 정답: ({정답문자}) {정답 선택지 전문}
원어민의 감각: ...
핵심 문법 포인트: ...
문장 한글 해석: ...

섹션 사이는 JSON 문자열 내부에서 `\n`으로 구분하세요.

전체 설명은 보통 5~8개의 자연스러운 한국어 문장으로 작성하세요.

[정답]
실제 문항 번호, 정답 문자, choices[answer]의 정확한 표현을 사용하세요.

[원어민의 감각]
문법 용어부터 설명하지 마세요.
먼저 실제 업무 상황에서 무엇을 말하려는 문장인지 설명하세요.

친근한 존댓말을 사용하되,
“이런 상황이라면 어떻게 말할까요?”
“두 표현은 찰떡궁합이에요.”
같은 표현을 모든 문제에 반복하지 마세요.

[핵심 문법 포인트]
문법, 품사, 구조, 의미, 연어 중 실제 정답을 결정하는 핵심을 정확하게 설명하세요.

오답 세 개도 이 문맥에서 왜 탈락하는지 설명하세요.
