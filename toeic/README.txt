영어만점 Part 5 · 6 · 7

실행: ZIP 전체를 압축 해제한 뒤 index.html을 여세요.

추가된 기능
- 실제 시험장 모드: 현재 Part의 모든 문제를 실제 시험지형 2단 레이아웃에서 한 번에 풀이
- 풀이 중에는 정오답과 해설을 숨기고, 전 문항 응답 후 정답 확인을 눌러 별도 결과 페이지에서 채점·해설 확인
- Part 5는 문항 2단, Part 6은 지문 전폭+문항 2단, Part 7은 단일·복수 지문 폭을 구분한 뒤 문항 2단으로 표시
- Part 7 단일·이중·삼중 지문 표시 및 파트별 정오답/별표 기록
- Part 7 기본 예제 3세트, 12문항 (완전한 54문항 세트가 아닌 기능 체험용 자체 제작 예제)
- 풀이 후 정답의 지문 근거, A~D별 정답/오답 이유, 전체 지문 한국어 해석 표시
- Part 7 예제 복원은 삭제된 기본 예제만 추가
- 현재 Part에서 오답·별표만 남기기는 보존 대상이 아닌 문제와 관련 기록을 확인 후 삭제

파트별 AI 문제 생성 및 업로드
1. 파트별 문제 업로드를 열고 Part 5, Part 6, Part 7 중 하나를 선택
2. 선택한 파트에 맞게 바뀐 요청문을 복사해 사용하는 AI에 전달
3. Part 5는 30문항, Part 6는 16문항, Part 7은 54문항의 JSON 배열을 각각 받기
4. JSON 파일을 선택하거나 JSON 내용을 직접 붙여넣어 등록
5. 검사에 통과하면 선택한 파트에만 문제가 추가되고 해당 파트 화면으로 이동
앱이 직접 AI를 호출하지는 않습니다. 다른 파트가 섞인 JSON이나 미완성 응답은 등록되지 않습니다.

문제 난이도와 실전성
- 전체 체감 난이도는 중상이며, 중 20%·중상 60%·상 20%를 권장합니다.
- 희귀 단어와 전문 지식이 아니라 문맥, 연어, 바꿔 말하기, 정보 연결로 난도를 조절합니다.
- 실제 TOEIC 문항을 복제하지 않고 직장 및 일상생활의 의사소통 상황을 새로 설계합니다.
- Part 5는 문법·기능어와 어휘·연어를 균형 있게, Part 6는 문장 간 연결을, Part 7은 세부 정보·추론·문서 간 연결을 중점적으로 검수합니다.

독창성·정답 검수 설정
- 기출·교재·웹 문항 복제 및 이름·숫자·단어만 바꾸는 근접 변형 금지
- 새로운 상황, 문서 관계, 수치, 조건, 질문, 보기, 해설을 처음부터 설계하도록 지시
- 1차 구조·문맥 검수, 2차 정답·번역·해설 일치 검수, 3차 정답을 가리고 다시 풀기 및 모든 오답 대입 검수
- 문서 간 날짜·인물·금액의 일관성, NOT/EXCEPT, 추론 과장, 복수 정답 가능성 점검

앱이 자동 검사하는 범위
- 선택한 파트 이외의 문제 포함 여부, 파트별 문항 수, Part 7 번호 147~200 중복·누락, 단일/이중/삼중 세트 수
- Part 6 빈칸 표식, 동일 지문 일치, 정답 분포 및 연속 패턴
- 네 보기의 중복, 필수 설명과 번역 누락, Part 7 근거 인용이 실제 지정 문서에 있는지
- 복수 지문마다 연계 문항 존재 및 서로 다른 두 문서 이상의 근거
- 문장 삽입 유형의 위치 표식과 보기 형식
자동 검사는 구조와 근거 문자열을 확인합니다. 의미상 정답의 유일성, 해설의 타당성, 기존 저작물과의 유사성을 자동으로 보장하지 않습니다. AI 검수 지시와 함께 최종 내용 검토가 필요합니다.

보관 및 호환성
기존 Part 5·6 저장 키를 유지하며 Part 7은 별도로 저장합니다. 브라우저나 파일 경로가 달라지면 예전 학습 기록에 접근하지 못할 수 있습니다. 기존 ZIP은 덮어쓰지 않고 보관하세요.
초기화/삭제는 현재 선택한 파트에만 적용됩니다.
